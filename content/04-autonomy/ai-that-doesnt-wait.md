# AI That Doesn't Wait to Be Asked

An agent becomes more useful when the work can begin because something happened, not only because you opened a chat window.

The trigger might be simple: every Monday morning, a folder receives a new document, a task changes status, or a deadline approaches. The agent reads the relevant context from [[01-memory-and-knowledge-graphs/why-memory-changes-everything|the durable record]], performs a bounded step, and leaves an artifact for review.

That is autonomy in its useful form. It is not a vague instruction to “keep working.” It is a repeatable loop with a clear beginning, a clear scope, and a visible result.

Start with work where a missed run is inconvenient rather than catastrophic. For example: collect the week’s research links into a reading note; summarize new items in a project folder; prepare a draft agenda from an existing calendar. Each task should have [[dont-grade-your-own-homework|a way to tell whether it succeeded]] and a person prepared to move [[from-operator-to-reviewer|from operating every step to reviewing the result]].

The moment an agent can take an irreversible action, the design changes. Sending a message, changing a customer record, or spending money needs stronger permissions and review. Earn autonomy in stages: read first, draft next, act only after the system has shown it can be trusted.
