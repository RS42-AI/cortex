# Resources

These are starting points for the course. The important work is to use them on a small project of your own, not to collect more tabs.

## Standards & documentation

- **Model Context Protocol** — [modelcontextprotocol.io](https://modelcontextprotocol.io) — the protocol introduced in [[02-connections-mcp/mcp-a-universal-port-for-ai|MCP: A Universal Port for AI]].
- **Anthropic engineering** — [anthropic.com/engineering](https://www.anthropic.com/engineering) — practical writing about building and evaluating agentic systems.

## Tools for building your own knowledge graph

- **Obsidian** — [obsidian.md](https://obsidian.md) — one way to build a linked-note knowledge base; see [[01-memory-and-knowledge-graphs/a-knowledge-graph-is-shared-memory|A Knowledge Graph Is Shared Memory]].
- **Quartz** — [quartz.jzhao.xyz](https://quartz.jzhao.xyz) — the open-source publishing tool used for Cortex.
